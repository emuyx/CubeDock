# nemc-tan-lobby-solver (local copy)

This directory is a locally maintained copy of the components CubeDock uses
from `github.com/Happy2018new/nemc-tan-lobby-solver`. The original upstream
repository has been deleted by its author.

The remaining subdirectories are covered by their own MIT licenses and notice
files. CubeDock removed the unused demo programs and replaced the previously
unlicensed `bunker` package with a clean-room implementation. See [NOTICE](NOTICE)
and [LICENSE](LICENSE) for the local glue and the upstream attributions.

This copy is maintained only for CubeDock; do not treat the entire directory as
a single upstream release. When upgrading, review every new file's license.
