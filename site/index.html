三步开房，慢慢来

第一次用不用一次全搞定，跟着页面走就好 (｡•ᴗ•｡)

  1. 01

    下载并打开

    去 Releases 下载对应系统的压缩包，解压后 Windows 双击 CubeDock.exe； Linux / macOS 在终端运行解压出的程序（必要时先 chmod +x）。 第一次打开会自动弹出浏览器，地址一般是 http://127.0.0.1:18321/。

  2. 02

    填好服务器和账号

    在控制台设置管理员密码，按向导填服务器地址；再到「账号与房间」登录网易账号。 不知道选什么方案？先用默认的代理模式就好，之后随时能改。

  3. 03

    启动房间，叫上朋友

    在账号仪表盘点「启动」，房间在线后把房间号发给朋友， 或者让他们在网易版 Minecraft 的「本地联机」里搜索。 玩家、好友申请和日志都在这个仪表盘里。

WHY CUBEDOCK

日常用得到的，都收进控制台了

不用记命令，也不用翻配置文件。能点的都放在网页里。

一个账号，一间房

每个账号单独启动、停止、重连；房间号、玩家、好友申请和日志都收在同一个仪表盘里。

网易账号都能登

互通版邮箱/密码、网易手游、4399 手游都支持。新号还没游戏名也没关系，先登录再起名就好。

代理 / 转服都能用

默认代理模式最省事；需要大厅、预载资源包或让服务器看到真实 IP 时，再切到转服模式。

配置方案

服务器、房间、资源包和提示页面按方案保存。复制一份改改地址，就能开新服。

房间里的琐事

标签、准入等级、房间成员、好友申请和踢人，都能在网页里处理，不用去翻控制台命令。

数据留在本机

登录凭证加密保存在自己电脑上，控制台默认只监听 127.0.0.1，不会把账号传到别处。

CONNECTION MODES

代理还是转服？先选一个就好

拿不准就用代理模式，之后在「配置方案」里随时能改。

推荐先试

代理模式

玩家先连到 CubeDock，再由 CubeDock 转发到你的服务器。不用额外开大厅，配置最少。

玩家→CubeDock→你的服务器

适合

  • 想尽快把房间开起来
  • 服务器已经支持网易协议
  • 不需要服务器看到玩家真实 IP
最省事 · 默认先用这个
需要时再用

转服模式

玩家先进本地小大厅，预加载资源包，再跳到你的服务器。适合需要大厅或想让服务器看到真实 IP 的情况。

玩家→本地大厅→你的服务器

适合

  • 客户端能直接连到服务器
  • 资源包未加密、不会频繁变化
  • 想让服务器看到真实 IP / 延迟
资源包前置 · 服务器看到真实 IP
小提醒：不管哪种模式，服务器都要原生支持网易 RakNet v8；标准 BDS 不能直接用。 服务器不支持的话，两种模式都帮不上忙啦。
FAQ

常见问题

先看看这里；更多问题在 使用文档 和控制台的「常见问题」页里。

代理和转服怎么选？

拿不准就先用代理模式：开房最快，也不用额外开大厅。需要先进入本地大厅、预加载资源包，或者想让服务器看到玩家真实 IP 时，再在「配置方案」里切到转服模式。

标准 Bedrock Dedicated Server 能直接用吗？

不能哦。服务器必须原生支持网易 RakNet v8，两种模式都一样；CubeDock 不会把网易协议翻译成标准 Bedrock。选服务器之前可以先问一下服务商 (・∀・)

配置方案、账号和房间是什么关系？

配置方案保存服务器、房间和资源包设置；一个账号选用一套方案，对应一间房。多个账号可以共用一套方案，也可以各用各的。切换方案前要先停止全部房间，下次启动时生效。

手机搜不到房间 / 开房失败怎么办？

先确认账号能正常登录、没有在别的设备上登录，房间也已经显示为在线。如果提示需要安全验证（1351），按页面提示完成验证，再点一次「登录并添加」就好。

玩家进来马上就断开？

先看服务器是否支持网易协议、版本是否接近、资源包是否一致。转服模式还要确认玩家能直接连到服务器。还是不行的话，到「诊断」页复制报告，错误信息会写得更清楚。

控制台打不开 / 忘记管理员密码？

默认地址是 http://127.0.0.1:18321/。忘记密码时，先停止程序、备份数据目录，再删除里面的 admin.json，重启后重新创建管理员就行。

一个网易账号能开几个房间？

一个账号对应一间房。同一账号重复登录会把前一个房间挤下线；多开几个账号就能同时开几间房。实际数量主要看电脑资源和网易那边的限制。

账号数据安全吗？

登录凭证保存在本机数据目录，Windows 用 DPAPI 加密，其他平台用 0600 权限。控制台默认只监听本机，不会把账号上传到别处。记得不要把这些数据文件发给别人。
